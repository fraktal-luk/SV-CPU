

# Groups of operations:

― General-computational
	FP/int result
	rounding
	might exception

― Quiet-computational
	FP result
	not exception

― Signaling-computational
	no FP result
	might exception

― Non-computational
	no FP result
	no excpetion

Parallel classification:

― homogeneous
	FP operands and FP result - the same format

― formatOf
	indicate format of result, independent from operands
